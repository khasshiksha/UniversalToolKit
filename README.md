\# 🧰 Universal Toolkit



\*\*All-in-one offline toolkit for PDF, Image, Video \& Audio\*\*



A powerful, privacy-first desktop application that works 100% offline. No uploads, no accounts, no watermarks — your files never leave your computer.

\## ✨ Features



\### 📄 Document Tools (7)

\- 🔗 \*\*Merge PDF\*\* — Combine multiple PDFs (drag to reorder)

\- ✂️ \*\*Split PDF\*\* — Extract pages or split into individual files

\- 🗜️ \*\*Compress PDF\*\* — Reduce file size (metadata + object streams)

\- 🔄 \*\*Rotate PDF\*\* — Rotate all or specific pages (90°/180°/270°)

\- 💧 \*\*Watermark PDF\*\* — Add text watermark (center/diagonal/footer)

\- 🖼️ \*\*Image → PDF\*\* — Convert JPG/PNG to PDF (A4/Letter/custom)

\- 📄 \*\*PDF → Image\*\* — Export pages as PNG (1×/2×/3× quality)



\### 🎨 Image Tools (10)

\- 🔄 \*\*Convert Format\*\* — JPG ↔ PNG ↔ WEBP

\- 📉 \*\*Compress\*\* — Reduce file size with quality control

\- 📐 \*\*Resize\*\* — Percentage or pixel dimensions

\- 🔃 \*\*Rotate / Flip\*\* — 90°/180°/270° + horizontal/vertical

\- 📸 \*\*HEIC Converter\*\* — iPhone photos → JPG/PNG

\- ✂️ \*\*Crop\*\* — Interactive canvas-based cropping

\- 🔲 \*\*Favicon Generator\*\* — 16/32/48/64/128/256 px icons

\- 🎨 \*\*Color Picker\*\* — HEX, RGB, HSL with copy buttons

\- 🖼️ \*\*AVIF Converter\*\* — Modern format conversion

\- 🔗 \*\*Merge Images\*\* — Combine images into PDF (A3-A8, layouts)



\### 🎬 Video Tools (8)

\- 🌐 \*\*URL → Video\*\* — Download from YouTube, Facebook, TikTok (1000+ sites)

\- ✂️ \*\*Trim / Cut\*\* — Interactive timeline trimming

\- 🔄 \*\*Convert Format\*\* — MP4 ↔ MKV ↔ AVI ↔ MOV ↔ WEBM

\- 🎵 \*\*Video → Audio\*\* — Extract MP3/M4A/WAV/FLAC

\- 🔗 \*\*Merge Videos\*\* — Join multiple videos

\- 📉 \*\*Compress Video\*\* — 4 compression levels + resolution cap

\- 📐 \*\*Resize Video\*\* — 4K/1080p/720p/480p/360p + custom

\- 📝 \*\*Add Subtitles\*\* — Burn SRT subtitles (size + position)



\### 🎵 Audio Tools (8)

\- 🌐 \*\*URL → Audio\*\* — Extract MP3/M4A/WAV from URLs

\- 🎤 \*\*Voice Recorder\*\* — Record from microphone

\- 🔄 \*\*Convert Format\*\* — MP3 ↔ M4A ↔ WAV ↔ FLAC ↔ OGG

\- ✂️ \*\*Trim / Cut\*\* — Cut any section

\- 🏷️ \*\*Metadata Editor\*\* — Edit title, artist, album, year, genre

\- 🔗 \*\*Merge Audio\*\* — Join multiple audio files

\- 🎼 \*\*Audio → Video\*\* — Combine audio with still image

\- 🎙️ \*\*Noise Reduce\*\* — Remove background noise



\*\*Total: 33 tools\*\*

\## 🔒 Privacy First



Unlike online tools (iLovePDF, SmallPDF, TinyPNG), \*\*Universal Toolkit\*\*:



\- ✅ \*\*Never uploads your files\*\* — Everything is processed locally

\- ✅ \*\*No account required\*\* — Just download and run

\- ✅ \*\*No watermarks\*\* — Free forever

\- ✅ \*\*Works offline\*\* — No internet needed (except URL downloads)

\- ✅ \*\*Open source\*\* — Verify the code yourself



Your bank statements, medical reports, and contracts stay \*\*on your computer\*\*.

\## 🚀 Installation



\### Windows 10/11



1\. Download `Universal Toolkit Setup 1.0.0.exe` from \[Releases](../../releases)

2\. Run the installer

3\. If Windows Defender shows a warning, click \*\*More info\*\* → \*\*Run anyway\*\*

4\. Launch from Desktop shortcut



That's it! No Node.js, no dependencies needed.
